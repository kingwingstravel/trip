# King Wings — как всё устроено (инструкция для владельца и любого программиста)

Написано 20.11.2026. Цель: чтобы сайты и путеводители работали и обновлялись **без Claude и без конкретного программиста**.
Любой веб-программист разберётся за час. Всё простое: готовые страницы (HTML), без баз данных и без WordPress-плагинов.

| Что | Где | Заметка |
|---|---|---|
| Код всех сайтов | GitHub, аккаунт **kingwingstravel** (вход через partnerships@kingwingstravel-dmc.com) | Владелец — King Wings. Программистам давать доступ «Collaborator» и забирать, когда нужно |

Правило: никому не отдавать владение. Только доступ, который можно забрать.

## 2. Что где лежит

### Репозиторий `kingwingstravel/trip` (открытый) → trip.kingwingstravel-dmc.com
- `g/<код>/` — путеводители групп. Каждая страница **зашифрована PIN-кодом группы**, в открытом виде данных туристов нет.
- `tools/` — сборка путеводителя: `build_guide.py` (данные → страница), `publish.py` (шифрование PIN), `template.html` (вид).
- `tools/autopilot/` — **автопилот** путеводителей (раздел 4).
- `menu/` — меню ресторанов для групп.
- `live.json` — живые цифры для сайта агентов («сейчас в пути N групп»).
- Сайт сам выкладывается через GitHub Pages (Settings → Pages), адрес trip.kingwingstravel-dmc.com.

### Репозиторий `kingwingstravel/galeri` (закрытый)
- `programs/` — **сайт программ для агентов** kingwingstravel-dmc.com/programs/ (5 языков: EN, ID, TR, ES, HI).
- `tools/`, `content/groups/` — **галерея** kingwingstravel-dmc.com/galeri/.
- `apps-script/Code.gs` — скрипт Google-таблицы «Галерея сайта».
- Сборка: GitHub Actions. Готовые сайты лежат в ветках `programs-site` и `site`; Hostinger (раздел Git) забирает их в `public_html/programs` и `public_html/galeri`.

## 4. Путеводители

### Обычный путь
1. В папке группы (Туризм / b2b / агент / год / 1. Confirmed / месяц / группа) есть таблица «🟡 Путеводитель — …».
2. Заполнить жёлтые клетки, лист «Туристы» (имена, комнаты, билеты), поставить галочку **B23 «✅ Опубликовать»**.
3. Утром страница появится, ссылка и PIN — в клетке **B25**, код для гида и агента — **B26**. Код и PIN группы никогда не меняются.

### Автопилот (запасной, без Claude)
Включается сам, если задача Claude не работала 2 дня. Сначала сам заполняет таблицы «Путеводитель» из файлов партнёра в папке группы (ИИ Gemini, ключ на аккаунте King Wings): создаёт таблицу, если её нет, и заполняет только пустые клетки и «?» — то, что вписал человек, не трогает. Цены и паспорта не пишет. Всё заполненное отмечает в B24 «🟡 Заполнил автопилот — проверьте». Галочку «Опубликовать» (B23) ставит только владелец. Потом публикует страницы групп с галочкой.
Чем хуже Claude: если колонка на языке группы пустая — перевод Google Переводчиком; места сбора со стрелкой — только если в клетке есть координаты; гид пишется один на всю поездку (как в B16).
Пока работает Claude, автопилот ничего не делает. Страницы автопилота помечены файлом `g/<код>/auto` — Claude их потом пересоберёт.

**Установка (один раз, 5 минут, делает Давид):**
1. Открыть script.google.com под аккаунтом King Wings → «Новый проект» → назвать «KW автопилот путеводителей».
2. Скопировать весь текст файла `tools/autopilot/KW_Guide_Feed.gs` (GitHub trip) и вставить вместо пустого кода → Сохранить.
3. Сверху выбрать функцию **setup** → «Выполнить» → разрешить доступ (Google спросит про Диск и Таблицы — это нормально).
   Внизу в журнале появится строка «КЛЮЧ: …» — скопировать.
4. «Развернуть» → «Новое развертывание» → тип «Веб-приложение» → «Запуск от имени: я», «У кого есть доступ: Все» → «Развернуть» → скопировать адрес, он заканчивается на `/exec`.
5. GitHub → репозиторий **trip** → Settings → Secrets and variables → Actions → **New repository secret**:
   имя `GUIDE_FEED`, значение: `<адрес …/exec>?k=<КЛЮЧ>` (например `https://script.google.com/macros/s/AKfy…/exec?k=3f9a…`).
6. **Ключ Gemini (автозаполнение таблиц без Claude):** aistudio.google.com под аккаунтом King Wings → «Get API key» → «Create API key» → скопировать.
   В редакторе скрипта: шестерёнка «Настройки проекта» → внизу «Свойства скрипта» → «Добавить свойство»: имя `GEMINI_KEY`, значение — ключ → Сохранить.
   Проверка без риска: выбрать функцию **testFill** → «Выполнить». Скрипт заполнит КОПИЮ путеводителя по файлам группы Ilham в папке «Claude Testing» (настоящие таблицы не трогает). Открыть её и посмотреть.
7. Проверка: GitHub trip → Actions → **Guide autopilot** → Run workflow → галочка force → Run. Через 2–5 минут зелёная галочка, в журнале список групп.
   Внимание: с галочкой force он **опубликует** версии автопилота (их потом пересоберёт Claude). Для проверки без публикации можно не ставить force — тогда он просто скажет «Claude работает».

Без ключа скрипт ничего никому не отдаёт. Ключ хранится только в секретах GitHub.

## 5. Сайт программ для агентов (kingwingstravel-dmc.com/programs/)

**Проще всего — через «Админку King Wings»** (веб-приложение в Google-аккаунте King Wings, код: репозиторий galeri → `apps-script/admin/`):
цены, показать/скрыть программы, порядок по языкам, тексты по дням, продажи (цена, бронь, оплата, реквизиты), показ в Google, список групп с PIN.
Нажали «Сохранить» — через 2–3 минуты на сайте. Установка: см. начало файла `apps-script/admin/Code.gs`. Настройки сайта лежат в `programs/settings.json`.

Без админки — то же самое вручную:

Все правки — в GitHub (репозиторий galeri) прямо в браузере: открыть файл → карандаш «Edit» → «Commit changes». Через 2–3 минуты сайт обновится сам.

- **Программа** = один файл `programs/content/NN-название.json`. Внутри блоки на языках (`en`, `id`, `tr`, `es`, `hi`): название, маршрут, отели, дни, что включено. В каком порядке показывать: `order`, для отдельного языка `order_es`, `order_tr`.
- **Новая программа**: скопировать похожий файл, поменять `slug` (адрес страницы), тексты и дни. Сборщик сам проверит, что дней столько же, сколько в маршруте.
- **Фото**: только настоящие, из галереи: `"cover": {"ref": "<папка группы в галерее>#NN"}`.
- **Цены** (когда готовы): в файл программы добавить
  `"prices": {"3": {"bo": {"10": 1450, "15": 1320, …}, "fb": {…}}, "4": {…}}`
  (3/4 — звёзды отеля, bo — только завтраки, fb — полное питание, 10/15/20… — от скольких гостей, цена в USD за человека).
  Затем в `programs/build.py` вверху: `SHOW_PRICES = True`, `SHOW_BOOK = True`. Сайт сам покажет цену, сумму за группу и депозит 30 %.
- **Банк**: в `programs/build.py` заполнить `BANK = {...}` и `BANK_SHOW = True`. **Ссылка на оплату**: `PAY_URL = 'https://…'`.
- **Показ в Google**: сейчас сайт скрыт (`INDEX = False`). Включать, только когда готова вся цепочка продажи: `INDEX = True`, потом добавить сайт в Google Search Console.
- **Аналитика**: `METRICA_ID` (Яндекс Метрика — стоит), `GA4_ID`, `CLARITY_ID` — вписать номера, если появятся.
- Тексты интерфейса: EN и ID — в `programs/build.py` (словарь `T`), TR/ES/HI — в `programs/i18n.py`.

Условия оплаты на сайте: депозит 30 % (не возвращается), остаток 70 % за 30 дней до заезда, отмена: 31+ дней — только депозит, 15–30 дней — 50 %, 0–14 дней — 100 %.

## 6. Галерея (kingwingstravel-dmc.com/galeri/)
Ведётся из Google-таблицы «King Wings — Галерея сайта»: добавить группу, фото, текст, галочку «Опубликовать» → скрипт сам кладёт в GitHub → сайт пересобирается.
Страница идёт в Google, только если текст ≥60 слов и ≥4 фото; вся галерея скрыта, пока нет 4 таких групп.

## 7. Если что-то сломалось
- **Сайт не обновился**: GitHub → репозиторий → Actions → красный крестик → открыть → внизу текст ошибки. Обычно это опечатка в JSON (лишняя/нет запятой, кавычки). Исправить файл — сборка запустится снова.
- **Вернуть как было**: GitHub → Commits → нужное изменение → «Revert».
- **Путеводитель не открылся**: проверить галочку B23 и что в таблице нет «#ERROR». PIN и ссылка — в B25.
- **Hostinger не подтягивает сайт**: hPanel → Git → проверить, что ветка `programs-site` → `public_html/programs`, `site` → `public_html/galeri`, нажать Deploy.

## 8. Правила, которые нельзя нарушать
- Путеводители **никогда** не показываются в Google (noindex) и всегда закрыты PIN.
- В репозитории — никаких паспортов, дат рождения, цен нетто, наценок, имён поставщиков. Данные туристов — только в зашифрованных страницах.
- Только настоящие фото и настоящие цифры. Ничего не придумывать.
- Сайт должен оставаться лёгким и быстрым: без тяжёлых плагинов, без лишних скриптов.
- Ссылки и PIN выданных групп не менять никогда.
